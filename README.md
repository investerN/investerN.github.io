# スワップサヤ取りウォッチ

国内FX業者のスワップポイントを毎日自動収集し、業者間のサヤを証跡付きで公開しているサイトです。

<https://investern.github.io/>

## このリポジトリについて

**このリポジトリの中身はすべて自動生成物です。直接編集しないでください。**
編集しても次回のデプロイで上書きされます。

- 生成元のコードとワークフローは別の非公開リポジトリにあります
- 毎日 12:00（日本時間）に自動で更新されます
- `data/history/` には日次スナップショットが蓄積されます（推移グラフの元データ）
